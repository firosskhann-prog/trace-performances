TRACE — STEP 1 (NEON -> MOON)

UPLOAD THESE 4 FILES TO THE ROOT OF YOUR EXISTING GITHUB REPOSITORY:
  index.html
  compile.html
  target-neon.png
  response-moon.jpg

Then:
1. Open:
   https://firosskhann-prog.github.io/trace-performances/compile.html

2. Press: MAKE targets.mind
   Wait until it says Ready.

3. Press: DOWNLOAD targets.mind

4. Upload the downloaded targets.mind to the ROOT of the same GitHub repository.

5. Open your normal audience link:
   https://firosskhann-prog.github.io/trace-performances/

6. Press START TRACE, allow camera, and point the phone at the NEON image.
   The MOON should appear anchored over the NEON target when MindAR recognises it.

IMPORTANT:
- GitHub Pages may take around a minute after a commit to update.
- If the old page is cached, reload or use an incognito tab.
- For testing, display/print the NEON target reasonably large and keep it flat.
